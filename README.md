项目名称：基于 STM32 + FreeRTOS 的多功能测量仪器    
项目描述：基于 STM32F103RCT6 与 FreeRTOS 实现的多功能测量仪器，
          涵盖数字万用表、示波器、信号发生器、稳压电源监测四大功能。
主要工作：
  1. 软件架构：基于 FreeRTOS 多任务模型划分功能模块，负责整体软件架构设计
  2. 任务通信与同步：队列/邮箱传递测量数据，二进制与计数信号量完成任务与中断同步
  3. 资源共享保护：互斥锁保护示波器波形缓冲区，解决中断与任务并发访问的竞态问题
  4. 界面刷新机制：事件组实现 LCD 按需分区重绘，降低单片机无效刷新开销
  5. 定时任务：软件定时器实现示波器禁止触发间隔与强制触发
  6. 显示驱动：完成 ST7789 液晶 SPI + DMA 驱动
  7. 数据采集：ADC 注入序列多通道采集（万用表挡位测量、稳压电源电压监测）
  8. 波形输出：DAC + DMA 循环输出正弦波、三角波、方波等多种波形
  9. 触发链路：定时器 TRGO 触发 ADC/DAC，EXTI 外部中断触发波形采集
技术栈：C / STM32F103 / FreeRTOS / HAL / STM32CubeMX·CubeIDE /
        SPI / DMA / ADC / DAC / TIM / EXTI / ST7789
